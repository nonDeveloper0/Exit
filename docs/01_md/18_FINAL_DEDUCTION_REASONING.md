# 18. 최종 추리 — 서술형 근거 제출 (진행 문서)

최종 추리 제출 시, 범인 선택과 함께 **조가 추리한 근거를 서술형(장문)으로 함께 제출**하는 기능.

> 상태: **entry ID 확보 완료 → 코드 작업 진행.** 서술형 근거 entry ID = `1668977082`.

---

## 현재 제출 구조 (변경 전)

- 파일: `src/app/vote/page.tsx`
- 제출 방식: 구글폼으로 `no-cors` POST (응답은 못 읽지만 제출은 됨) + 기기 `localStorage`에 선택 저장
- 현재 전송 필드 3개:

```
FORM_URL = https://docs.google.com/forms/d/e/1FAIpQLSclsS9dAFGB2YgYNMNYd8NVQ5tBbdUBYwUF9tWosu5patyHXg/formResponse

entry.197462467  → 조 번호 (teamNumber)
entry.1747885092 → 제출자 이름 (name)
entry.795452093  → 선택한 범인 (suspect id)
```

- 투표 데이터는 **구글폼 + localStorage**에만 저장된다(현재 Supabase 저장 없음).

---

## 1단계 (먼저 진행) — 구글폼 수정

**운영자가 직접 해야 하는 단계.** 폼에 서술형 답변을 받을 칸이 없으면 텍스트가 버려지므로, 이 단계가 선행되어야 한다.

- [ ] 구글폼 편집에서 **"단락(장문형)" 질문**을 하나 추가한다.
  - 질문 예시: `추리 근거 — 범인으로 지목한 이유를 서술하세요`
- [ ] 새 질문의 `entry.숫자` ID를 확보한다.
  - 방법: 폼 편집 → 우측 상단 **⋮ → 미리 채워진 링크 가져오기(Get pre-filled link)** → 새 질문 칸에 임시 값 입력 → **링크 가져오기** → 생성된 URL에서 `entry.1234567=임시값` 형태로 ID 확인 → `entry.` 뒤 숫자만 기록.
- [ ] 확보한 `entry.숫자` ID를 이 문서 아래 "확정 값"에 적는다.

### 확정 값

```
서술형 근거 entry ID: entry.1668977082   (질문: "누가 범인이지?")
```

## 결정 필요 (2단계 전에 확정)

1. **필수 / 선택**: 서술형을 반드시 입력해야 제출 가능하게 할지, 비워도 제출 가능하게 할지.
2. **글자 수 제한**: 예) 300자 제한 + 카운터. 무제한으로 둘지.
3. **저장 위치**: 구글폼으로만 보낼지(현행과 동일), 운영자 실시간 확인을 위해 Supabase에도 저장할지.

> 기본안(미정 시): **선택 입력 · 300자 제한 · 구글폼으로만 전송**(현행 저장 방식 유지).

## 참고

- `no-cors` 특성상 제출 성공/실패 응답을 읽을 수 없다(현재도 동일). 실패해도 UI는 완료 처리된다.
- 최종추리 제출 상태 초기화는 `/admin` → 진행 상태 초기화 → `최종추리 제출 초기화`(브로드캐스트 `vote_reset`)로 처리된다. 서술형 추가와 무관하게 그대로 동작한다.
