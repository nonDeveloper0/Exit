# 엔딩 영상

## 형식

-   3분
-   흑백 스케치 애니메이션
-   대사 없음
-   내레이션만 사용

## 흐름

1.  시신 발견
2.  모두에게 동기가 있었음
3.  사건 당일 시간순 재구성
4.  김사원 폭행
5.  이대리 이탈
6.  나사장 지시
7.  나팀장-김사원 복도
8.  나팀장 대치
9.  우발적 살인
10. 은폐
11. 채소장 조작
12. 단서 연결
13. 진범 공개

## 연출

-   스케치가 그려지며 장면 생성
-   단서는 화면 위에 자연스럽게 오버레이
-   마지막 타임라인으로 모든 단서 연결
