# 수신전화 발신자 및 갤럭시 스타일 UI 디자인

## 목표

수신전화 오버레이의 발신자 표시를 `박미리` / `010-9876-2345`로 바꾸고, 수신 및 통화 중 화면을 최신 갤럭시 전화 앱에 가까운 형태로 개선한다.

## 범위

- 수정 대상은 `src/components/IncomingCallOverlay.tsx`와 필요한 전역 애니메이션 CSS로 제한한다.
- 전화 이벤트 수신, 수락 시 `CALL01` 수집, 오디오 재생, 벨소리, 진동, 수신 전용 기기 제한은 유지한다.
- 문서/진행 기록은 `progress.md`에 반영한다.

## 디자인

- 수신 화면은 어두운 청록/남색 그라데이션 배경, 상단 상태줄 느낌, `Incoming call` 라벨, 큰 발신자 이름, 번호, 중앙 원형 아바타, 하단 통화 액션으로 구성한다.
- 기존 밀어서 받기 제스처는 유지하되 갤럭시 통화 수락의 초록색 원형 버튼을 노브로 보이게 한다.
- 거절은 빨간 원형 버튼과 텍스트로 보이게 하며, 실수 터치를 줄이기 위해 기존처럼 별도 버튼으로 둔다.
- 통화 중 화면은 같은 프로필과 번호를 유지하고, 통화 시간/파형/종료 버튼을 배치한다.

## 검증
